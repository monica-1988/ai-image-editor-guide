Wizmade / Image editing guide

Plan a clear edit. Inspect the result.

An AI image edit starts with a specific change, a suitable reference photo, and a careful review. This guide walks through preparing an edit for the Wizmade image editor.

1. Prepare the original image

Choose an image you have permission to edit. Keep an unchanged copy. A clear subject and visible edges make it easier to describe what should change and what should stay.

2. Describe one change at a time

For a local edit, identify the object, its position, and the replacement. Include the details you want to preserve. When changing a background, describe the setting, light direction, and shadows.

Replace the gray background with a sunlit studio. Keep the bottle shape, label text, camera angle, and original colors unchanged.

Use the image editing workbench to choose the available mode and prepare your instruction. An example or canvas preview is not proof that a processing task has finished.

3. Inspect the completed output

Compare the result with the original at full size. Check fine edges, lettering, hands, reflections, and any areas meant to remain unchanged. AI results can introduce artifacts; revise the instruction when the first result misses the intended change.

4. Keep the workflow explicit

Review the available model, generation requirements, and displayed credit cost before submitting a task. This guide does not promise free generations, a particular processing time, or automatic commercial rights.

To prepare a description from a reference image, explore Image to Prompt. To start an edit, open the Wizmade image editor.
